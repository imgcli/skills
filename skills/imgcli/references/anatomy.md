# Story and composition

Choose a story before choosing components. Start with the user's product, audience, language, real inputs and intended delivery format.

## Choose a source

- Use an available licensed template when its slots fit the brief. Follow its own delivery instructions; the free component CLI list is not a template catalog.
- Compose current components for a variable story, feature list or set of real product screens.
- Use footage or a small project-local component when the catalog does not provide the required behavior. A component with a similar name is not a substitute for a missing API.

## Map the beats

| Beat | Current choices | Content contract |
| --- | --- | --- |
| Problem or promise | centered-build, statement-cuts, strike-swap | Approved short copy in the user's language |
| Product identity | version-roll, app-open, lockup-draw | Actual name, version and supplied logo |
| Product in use | laptop-lid, phone-flow, phone-feature, device-trio | Real recording or screenshots, with accurate taps and captions |
| Work and result | checklist-run, run-log, agent-answer | States and results the real product supports; label simulations |
| Evidence | number-up, stat-grid, bar-chart, line-climb, unit-chart | Sourced numbers, units, dates and labels |
| Destination | lockup-draw, color-flood | One action and a real destination |

Select only useful beats. A logo bumper does not need a proof section; a product demo needs the actual product early. A storyboard is not an instruction to use every row.

## Budget the timeline

Read [the current index](components/index.md) and each chosen component's interface. Default preview frames assume the catalog's fps and default content. Longer text, more steps or a timing prop can change completion time. Convert seconds to the composition fps and inspect the final word or item.

Hard cuts can use Sequence or Series. For TransitionSeries, subtract overlaps from the total duration. Both scenes are mounted during an overlap: choose a presentation that keeps competing text readable and verify both sides of each cut. Standalone dot-wipe and block-wipe scenes do not implement TransitionSeries's presentation interface.

## Review the story

The viewer should be able to describe the problem, see the product address it, and understand the next step. Avoid a catalog dump or a succession of unsupported claims. Inspect the actual output at delivery size, then watch the encoded video with sound if it has audio. Report missing real content instead of passing fixtures off as customer evidence.
